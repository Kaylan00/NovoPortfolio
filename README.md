# Kaylan Argollo — Portfólio

Portfólio pessoal com estilo **cartoon/playful** — desenvolvido com HTML5, SCSS e JavaScript puro. Sem frameworks.

## Stack

- **HTML5** — semântico e acessível
- **SCSS** — estilo cartoon com variáveis, cores vibrantes e animações
- **JavaScript** — scroll reveal, tilt 3D, typing effect, parallax, glow mouse-follow
- **Google Fonts** — Lilita One (display) + Nunito (body) + JetBrains Mono

## Como rodar

Abra o `index.html` no navegador. O CSS já está compilado.

Para editar o SCSS:

```bash
npm install
npm run sass   # watch mode
```

## Personalização

Busque e substitua no `index.html`:
- `seu-linkedin` → seu LinkedIn real
- `seu-email@email.com` → seu e-mail real
- `Empresa Atual` → nome da empresa

Cores e estilo: edite as variáveis no topo do `styles/main.scss`.
